# 沃商圈 · 小微商户商机雷达

独立静态演示。参考 LocalSpark 商机雷达的“输入 → 重点结论 → 分层依据 → 行动”流程，采用大棚巡护版的大字、分栏和两端交互。没有修改 LocalSpark 或大棚版。

## 演示顺序

1. 在首页填写地址、行业、范围、经营阶段和目标，或直接使用默认的上海思南路样例。
2. 生成报告，切换三件本周行动，查看来源和建议步骤。
3. 展开位置、客群、本周信号、竞争、合作、实验六块依据。
4. 加入计划，编辑海报与文案，下载 SVG，填写执行反馈。
5. 切换客户经理端，查看同店反馈，筛选商户并保存跟进安排。

路由：`#home` 首页，`#report` 报告，`#manager` 客户经理端，`#message` 模拟消息。复制报告链接携带门店输入信息，不携带本机执行记录。

## 数据范围

- 默认样例使用 2026-10-20 留存的上海思南路公开 POI、上海城区天气预报和节假日安排。快照不是实时数据。
- 默认门店为阿娘面馆（锡荣别墅店），思南路 36 号。真实门店没有参与试点，不代表其实际经营、活动或采购意愿。
- 周边仅选择思澜新派本帮菜、RADAR COFFEE 两个公开样本，不代表完整商圈、同业数量、竞争强度或合作关系。
- 人口、实际人流、交易、收入、客户画像与活动效果未接入。人流图仅为明确标注的模拟界面，不参与建议和产品匹配。
- 其他地址展示数据待补齐与门店自查模板，不复用思南路的数据。半径是意向参数，没有完成地理检索和范围内商户统计。
- 行业会调整行动措辞，目标会调整优先顺序，阶段会调整试验提示。这是本地模板，不是实时模型推理。

## 功能与边界

可操作：输入生成演示报告、展开依据、计划、反馈、客户经理筛选与跟进、可编辑素材、复制文案及链接、报告和记录下载、打印入口、提醒频率保存。

没有实时高德查询、国内模型、短信、CRM、计费、真实邮件订阅或后台定时任务。提醒设置只保存在浏览器，不会发送消息。所有活动素材标注演示草稿。

本地存储键：`merchant-radar-demo-v1`。按门店地址、行业和名称隔离行动记录；两端在同一浏览器内联动，不能代替多用户权限和服务器同步。业务线索是待核实的反馈，不以模拟数据判断商户流失或强行推荐升档。

名称仅用于合作提案，没有联通 logo，不代表联通或任何门店授权。

## 运行与部署

四个静态文件 `index.html`、`style.css`、`data.js`、`app.js` 可由任意静态服务器托管，无依赖和密钥。GitHub Pages 从本仓库 main 分支根目录发布；推送更新会触发 Pages 发布。

与 LocalSpark 及大棚版没有自动源码同步。以后合并原仓库时，需单独接入数据、模型、认证、角色权限和消息服务。

## 已验证

- 脚本语法检查；1440 像素桌面、390 像素手机无页面横向溢出。
- 首页生成报告、三项行动切换、六块依据结构与来源展开。
- 改地址后不沿用样例来源或执行记录；特殊字符按文本显示。
- 行动计划、反馈联动、客户经理筛选和搜索空结果、跟进刷新后保留。
- 提醒设置刷新保留，但不发送通知。
- 编辑海报后的内容写入 SVG；模板尺寸为 1080 × 1440。
- 报告摘要、行动记录与试点清单下载；复制文案和报告链接。

未验证真实商户使用、付费转化、真实业务 API、跨账号同步或生成式模型效果。
